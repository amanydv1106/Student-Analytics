# StudIQ - Student Performance Analytics Frontend

Modern React + Vite web dashboard for the Student Success Prediction & Early-Warning AI system.

## Features
- **Predictor & Early Warning**: Instant student score prediction, risk gauge, personalized academic strengths, risk factors, and intervention advice.
- **What-If Scenario Simulator**: Interactive sliders for attendance, study hours, and missed deadlines with live before/after delta projections.
- **Model Leaderboards**: Comparison tables for Regression and Classification models, hyperparameter tuning parameters, and voting/stacking fusion architectures.
- **Domain Generalization Lab**: Analysis of model performance on held-out institutions (8 & 9).
- **Dataset & EDA Explorer**: Visual distribution plots, dataset statistical profile, and missing value rates.
- **Batch Predictor**: Evaluate cohorts of students at once with instant tabular results and CSV report export.

## Scripts

# Start development server with hot-reload (runs at http://localhost:5173)
